# Landing page artwork

`food-renders.png` was generated with the built-in ImageGen tool and is used as a transparent sprite sheet by `LandingPage.tsx` and `landing.css`.

## Generation prompt

Create a transparent PNG sprite sheet for an elegant food startup website, stylized-concept 3D clay and polished editorial food renders. Exactly five separate objects in five equal width columns across one horizontal row, no overlaps, every object entirely inside its own column, centered vertically. Left to right: broken Dubai chocolate bar with vivid pistachio filling; clear takeaway iced latte with dark brown straw; two birria tacos with herbs; thick pastrami sandwich on rye; mango-shaped orange ice cream on a wooden stick cut open to reveal creamy center. All objects similar visual scale, softly sculptural, realistic appetizing textures, soft studio shadows, slightly tilted playful poses. Transparent background. No text, no labels, no extra objects. Wide landscape image.
